# numo

A free, offline invoice creator. Fill in your details, preview the invoice live, and download it as a PDF — no accounts, no subscriptions, nothing leaves your browser.

**Live app:** https://al0tak.github.io/numo/

## Run locally

This project uses [pnpm](https://pnpm.io/).

```bash
pnpm install   # install dependencies
pnpm dev       # start the dev server
```

## Deployment

Pushes to `main` are built and deployed to GitHub Pages automatically.

**GitHub Actions:** https://github.com/al0tak/numo/actions/workflows/deploy.yml
